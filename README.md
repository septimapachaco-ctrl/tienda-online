# Tienda online

Este repositorio contiene un prototipo de tienda online responsive para un presupuesto de e-commerce con catálogo, carrito, checkout, pasarela simulada y panel administrativo.

## Cómo abrirlo

Puedes abrirlo directamente en el navegador desde el archivo `index.html`, o correr un servidor local:

```bash
python -m http.server 8000
```

Luego visita:

```text
http://localhost:8000
```

## Funcionalidades incluidas

- Catálogo con buscador y filtros por categoría
- Detalle de producto con variantes
- Carrito y resumen de compra
- Checkout con cliente, envío y método de pago
- Simulación de pago con Mercado Pago
- Panel de administración para productos, pedidos y clientes
- Reporte básico de ventas y gestión de estados
- Diseño responsive para móvil y escritorio
- SEO básico con meta tags, sitemap y robots

## Nota

Este es un prototipo front-end para demostración, sin integración real con APIs de terceros.
